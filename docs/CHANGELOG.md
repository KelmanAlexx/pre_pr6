# Журнал изменений

Формат основан на рекомендациях [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/). Версионирование релизов — по принципам Semantic Versioning.

## [1.1.0] - 2026-10-31

### Added
- Добавлена тихая установка обновления клиента АРМ.
- Добавлено создание ZIP-пакета и проверка контрольной суммы SHA-256.
- Добавлено резервное копирование `appsettings.json`, SQLite и кэша.
- Добавлены проверки Sanity Test после переключения версии.
- Добавлен автоматический откат к предыдущей версии при критической ошибке.
- Добавлено журналирование прогресса и формирование `test-report.json`.
- Добавлена отправка метрик в JSONPlaceholder.

### Changed
- Процесс установки разделен на подготовку, резервное копирование, переключение и проверку.

### Notes
- Сборка учебная: реальные бинарные файлы клиента и централизованный сервер распространения не входят в комплект.

## [1.0.0] - 2026-10-01

### Added
- Начальная версия клиентского модуля АРМ оператора ИС «Умный кампус».
- Локальная конфигурация, SQLite-база и каталог кэша.
